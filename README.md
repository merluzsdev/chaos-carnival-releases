# Chaos Carnival

Ein Party-Brettspiel über den Wolken für bis zu vier Freunde.

## Mitspielen

1. `ChaosCarnivalLauncher.exe` aus dem neuesten Release herunterladen und starten.
2. Der Launcher lädt das Spiel herunter, installiert es und hält es aktuell.
3. **SPIELEN** drücken. Einer hostet, die anderen treten mit dem Einladungscode oder der IP bei.
